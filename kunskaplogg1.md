## Vecka 38 – Ramverket och arbetssättet
**Kursmål:** Fullstack 4 

### Vad jag förstått
Fullstack 1: 

Vue är en JS ramverk som använder sig av komponenter som React, men till skillnad från den så hanterar den state på annat sätt. I vue komponenter 
uppdateras inte lika ofta som i React (varje gång något i komponent ändras), därför hanteras state inom en komponent på annat sätt. Vue använder
sig av rå html, ingen xml som för React. Hela konceptet är närmare till valilla js, där man har script och html kod separat från varandra och de 
kommunicerar via props.
